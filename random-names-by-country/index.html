Random Names by Country

Explore country-focused name generators with expanded banks of first names and surnames. Choose a country, create unique name batches, and read notes about spelling and naming patterns before using a result.

Browse the directory

Choose a country name generator

Each generator offers more than 100 masculine-associated given-name examples, more than 100 feminine-associated examples and more than 100 family-name examples. The lists are for creative inspiration and non-sensitive sample data; they are not official population rankings or civil-register databases.

  • German Name Generator: Explore German given names and family names, including common occupational surnames and spellings with umlauts. Use it for German-language fiction or a sample name that needs a recognisably German context.
  • Dutch Name Generator: Browse Dutch first names and family names with particles such as van, van der and de. It is useful when you want a Dutch-style surname structure or names for a Netherlands-based setting.
  • French Name Generator: Create French name ideas while retaining accents in names such as Émile and Chloé. The guide explains regional variation and why surname meanings should be checked rather than guessed.
  • Russian Name Generator: Explore given names, masculine and feminine surname forms, and an optional patronymic. Choose this tool when a fictional Russian full name needs a more complete traditional structure.
  • American Name Generator: Generate US name examples from a broad, culturally diverse pool. This page is useful for mockups and writing where the setting is the United States rather than one single ancestry.
  • Chilean Name Generator: Choose accented first names and either one surname or an illustrative two-surname format. Use it for Chile-focused writing, character drafts and non-sensitive sample data.
  • Chinese Name Generator: See selected Hanzi with Pinyin and the family name before the given name. Choose it when you want a Chinese-script example, while remembering that Pinyin alone does not determine unique characters.
  • Mexican Name Generator: Generate Mexican Spanish-language examples, including compound given names and an optional two-surname format. The guide explains the customary family-name order and the limits of sample data.
  • British Name Generator: Browse names used across the United Kingdom, with notes about England, Scotland, Wales and Northern Ireland. Use it for broad UK settings, then check specialist sources for regional language accuracy.
  • Japanese Name Generator: Explore Japanese name examples with kanji and readings. Choose this page when you need Japanese-script options rather than a Latin-letter country-name list.
How to use the directory

Pick a name bank that fits your setting

Choose a country page by the kind of output you need. For a quick fictional name, use a first-name or surname-only mode. For a complete character name, choose the full-name mode and check the country guide before settling on a spelling. The Chilean and Mexican tools offer two-family-name examples, the Russian page can add a patronymic, and the Chinese page shows Hanzi with Pinyin in family-name-first order.

Each country has its own bank and conventions. German surnames may preserve occupational or regional history; Dutch family names often include particles; French and Chilean spellings retain their accents; and UK naming patterns vary across its four nations. Chinese Pinyin can correspond to different Hanzi, while Russian patronymics and some surnames have gendered forms. Use the notes and references on the individual page when those distinctions matter.

Official statistics do not all measure the same thing: some sources count registered births in a specific year, some cover historic births, and others count surnames in a census or register. The generator banks are curated examples for inspiration, not complete government datasets or live popularity rankings. See the dated source notes on each country page for each reference’s scope.

When should you use each name generator?

Use first-name mode when you only need a given name for a character list or placeholder. Use surname mode to study spelling patterns or complete an existing draft. Choose full-name mode for a quick example, and use the specialist two-surname or patronymic controls when the format is relevant. For Chinese names, check the Hanzi as well as the Pinyin; for names with accents, keep the original diacritics when copying or exporting.

Names cross borders and naming customs vary between families and regions. A country label is a practical search filter, not proof of someone's identity. If you need a historically accurate or legally correct name, check an appropriate national or specialist reference and ask a fluent speaker when the language or script matters.
