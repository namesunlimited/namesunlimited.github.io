About Names Unlimited

Free online name generators for writers, game masters, parents, developers and anyone who needs a name quickly.

What is Names Unlimited?

Names Unlimited is a set of free online name generators for people who need a name quickly: parents looking at baby names, writers and game masters naming characters and places, people choosing a username, and developers who need sample data. Each tool is a single page that runs in your browser.

What tools are available?

People and baby names: baby names with meanings, random baby names, boy names and girl names.

Fiction and creative writing: character names, fantasy names, elf names, Japanese names, city names, school names and band names.

Online identity: the random username generator and the aesthetic username generator.

Utility tools: the fake name generator for test data and the random name wheel for picking a name from your own list.

There are also guides on choosing character names, usernames and baby names, and on using fake names for testing.

How are the names made?

The generators combine entries from built-in lists of names and word parts using simple patterns, and they do this in your browser. The lists are deliberately small, so repeats are normal, and the results work best as ideas to adjust. Some names in the fiction tools resemble names from books or games, so it is worth searching a name before you publish it.

Where a page shows a meaning or origin, such as the baby name and Japanese tools, the text is a short, simplified summary. Meanings and origins are often debated, and a Japanese name's meaning depends on the kanji chosen. These pages are not an authoritative reference.

How is the site maintained?

The site is built with plain HTML, CSS and JavaScript and is hosted on GitHub Pages. The source code is public in the Names Unlimited repository on GitHub. The site does not publish information about its authors, and this page does not make claims about a company or team. To report a mistake or suggest a tool, see the Contact page.
